Running.

There's no general-access page here by design — this tool works entirely through per-app and per-report links.

Run python seed.py "<Organization>" "<App 1>" ["<App 2>" ...] from omi-deepdive/backend to generate:

  • one /app/<token> link per app, to send to each app owner
  • one /report/<token> link for the consolidated report
